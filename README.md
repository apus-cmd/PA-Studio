# PA Studio per Windows 10 22H2 o Windows 11 a 64 bit
### Converti più PDF in PDF/A-1b con un’unica operazione

**P/A Studio è un’applicazione** per Windows, che semplifica la **conversione multipla di documenti PDF nel formato PDF/A-1b**. Un’interfaccia essenziale permette di aggiungere singoli file, trascinare più documenti o selezionare un’intera cartella, scegliere la destinazione e avviare il lavoro.

Il pacchetto completo include il motore di conversione e il profilo colore: non è necessario configurare percorsi o installare altri tools separatamente. La conversione avviene sul computer, senza caricare i PDF su servizi online.

**Funzionalità incluse**

- Conversione multipla: elaborazione in sequenza di più PDF, con esito per ciascun documento.
- Drag & drop: aggiunta di file e cartelle direttamente nella finestra dell’app.
- Selezione di cartelle: possibilità di includere anche le sottocartelle.
- Originali conservati: salvataggio delle copie convertite nella destinazione scelta, con nomi univoci.
- Controllo del testo: confronto del testo estratto prima e dopo la conversione; se cambia o viene perso, il risultato viene bloccato.
- Stato di avanzamento e annullamento: gestione del lotto dalla finestra principale.
- Rapporti di elaborazione: log per consultare gli esiti e gli eventuali errori.
- Avviso sulle dimensioni: segnalazione dei file che superano la soglia configurata.

 **Funzionalità compressione**

Per ridurre le dimensioni dei PDF puoi scegliere tre profili e personalizzare risoluzione e qualità delle immagini:

- Normale · immagini di buona qualità
- Forte · immagini di media qualità
- Estrema · riduzione più spinta, immagini di bassa qualità
- È disponibile anche l’ottimizzazione senza perdita, che interviene sulla struttura del PDF senza ricomprimere le immagini.

**Da Word a PDF, anche in blocco**

- Aggiungi più file .doc o .docx, scegli la destinazione e avvia l’esportazione usando Microsoft Word desktop installato sul PC. 
- Puoi richiedere anche il successivo passaggio in PDF/A-1b. 
- Se Word non è presente, la funzione viene disattivata con un messaggio.

**Funzionalità di Split & Join**

Possibilità di dividere un file per:
- intervalli di pagine di pagine
- numero di pagine
- dimensione massima 

Possibilità di unire più file nell'ordine preferito.

https://github.com/apus-cmd/PA-Studio/releases/download/release/PAStudio-Setup-1.7.3-Windows64.exe


**Requisiti e distribuzione**
Windows 10 22H2 o Windows 11 a 64 bit e .NET Framework 4.8. Il pacchetto include le librerie necessarie alla conversione. Per convertire i documenti non è richiesta una connessione Internet.
